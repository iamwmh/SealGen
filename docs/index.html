使用说明

SealGen 用来设计一枚可以 3D 打印的印章。印面在立体模型里是左右镜像的，盖出来的字才是正的。

设计印面

  1. 在「印面形状」里选择圆形、方形、椭圆、心形，或用手绘拖出轮廓。方形可以调圆角。手绘时按住拖动，松开后闭合；太短或太小的笔画不会被采用。
  2. 用「尺寸」设定印面的宽和高，单位是毫米。圆形会保持宽高一致。
  3. 在「文字与图案」里输入文字并添加，也可以添加图片或纹样（梅花、祥云、太极、芒纹、菱纹、回纹）。
  4. 选中一项后可以改字体、排版、粗体、字号、字距和旋转。排版包括横排、竖排、田字左起、田字右起、环排和增强排版。增强排版会把文字铺满边框内侧；多字默认从右往左竖排，换行可以自己分行。
  5. 在画布上拖动文字或图案。方向键微调，Delete 删除。

刻法和边框

阳刻笔画凸起，盖出来是红字。阴刻笔画凹陷，盖出来是白字。边框纹饰可选单线、双线、委角、回纹、拐子、花瓣、海水。粗细会同时改变线条和纹样，设为 0 就不要边框。阳刻边框是红线，阴刻边框是白线。

「印体」里的厚度是章身高度，凸起是笔画高出印面的距离。需要手柄时打开「加手柄」。精度决定印面网格的细腻程度。

预览

中间的「钤印效果」是盖在纸上的样子，文字是正的。切换到「镜像」可以看到刻在章面上的方向。正在手绘外形时不能切换镜像。

右侧是立体印章。印面上的字是镜像的，盖出来才是正的。

导出和打印

导出按钮在立体预览下方。导出 STL、3MF 或 OBJ。文件单位是毫米，印面朝上，可在 Cura、Bambu Studio、PrusaSlicer 中打开。也可以导出印稿 PNG，那一张始终是未镜像的钤印效果。

打印时把印面作为朝上的那一面。如果打开了手柄，背面可能需要支撑。

Guide

SealGen designs a seal you can 3D print. The solid is mirrored left to right, so the stamped impression reads correctly.

Design the face

  1. Under Face, choose Circle, Square, Oval, or Heart, or draw an outline. Squares can have rounded corners. For a drawn shape, drag a loop and release to close it. A stroke that is too short or too small is not used.
  2. Set the width and height in millimeters. A circle keeps both sides equal.
  3. Under Content, type characters and add them. You can also add an image or a motif: Plum, Cloud, Taiji, Rays, Diamond, or Meander.
  4. Select an item to change its font, layout, bold setting, size, spacing, and rotation. Layouts are Horizontal, Vertical, Grid left, Grid right, Ring, and Fill face. Fill face enlarges the characters inside the border. Several characters run in columns from right to left unless you insert line breaks.
  5. Drag characters or artwork on the canvas. Arrow keys nudge, and Delete removes the selection.

Carving and border

Relief raises the strokes so they print red. Intaglio recesses them so they print white. Borders are Line, Double, Notched, Meander, Fret, Petal, and Waves. Weight changes the lines and the ornament together. Set it to 0 for no border. A relief border prints red, and an intaglio border prints white.

Depth is the body thickness. Raise is how far the strokes stand above the field. Turn on Add a handle if you want one. Detail controls how fine the face grid is.

Preview

Impression, in the center, is how the seal prints on paper. Switch to Mirror to see the direction cut into the seal. The switch is unavailable while you are drawing an outline.

The solid seal is on the right. The characters on that face are mirrored, so the stamped impression reads correctly.

Export and print

The export buttons sit under the solid preview. Export STL, 3MF, or OBJ. Units are millimeters and the face points up. The files open in Cura, Bambu Studio, and PrusaSlicer. Export PNG saves the impression, which is never mirrored.

Print with the face on top. A handle may need supports on the back.
